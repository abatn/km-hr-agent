## 7. Heimatländer – Lokale Suche via anysearch

> **Zweck:** Kandidaten finden lokale Sprachschulen/Privatlehrer in ihrem Heimatland,
> BEVOR sie auswandern. Agent nutzt `anysearch.search` (anonymous Access).
> **Quelle:** `nationalitaet`-Feld in der `candidates`-Tabelle.

### Suchmuster (generisch für jedes Land)

| Sprache | Query-Beispiel | Erwartung |
|---|---|---|
| Deutsch | `"Deutschkurs [Stadt] [Land]"` | Lokale Sprachschulen |
| Deutsch | `"Goethe-Institut [Land]"` | Filialen (falls vorhanden) |
| Deutsch | `"private Deutschlehrer [Land]"` | Einzelunterricht |
| Deutsch | `"online Deutsch lernen [Land]"` | Online-Plattformen |
| Französisch | `"cours allemand [Ville] [Pays]"` | FR-sprachige Suche |
| Englisch | `"English course [City] [Country]"` | Online + Präsenz |

### Tunesien (Beispiel)

| Was | Query | Erwartetes Ergebnis |
|---|---|---|
| Goethe-Institut | `"Goethe-Institut Tunis"` | Filiale + Kursangebote |
| Lokale Schule | `"Deutschkurs Tunis"` | Private Anbieter |
| Online | `"online Deutsch lernen Tunesien"` | italki, preply, etc. |
| Privatlehrer | `"private Deutschlehrer Tunis"` | Einzelunterricht |

### Marokko (Beispiel)

| Was | Query |
|---|---|
| Goethe-Institut | `"Goethe-Institut Casablanca"` |
| Lokale Schule | `"Deutschkurs Rabat"` |
| Online | `"online Deutsch lernen Marokko"` |

### Generischer Ansatz (für jedes Land)

1. Kandidat hat `nationalitaet` (z.B. "Tunesisch")
2. Agent leitet Heimatland ab (z.B. "Tunesien")
3. Agent sucht via anysearch:
   - `"[Sprache]kurs [Hauptstadt]"` → lokale Schulen
   - `"Goethe-Institut [Land]"` → Filialen
   - `"online [Sprache] lernen [Land]"` → Online-Optionen
4. Ergebnis: Lokale + Online-Mix

### Warum anysearch?

| Vorteil | Begründung |
|---|---|
| Live-Daten | Kursangebote ändern sich häufig |
| Lokale Treffer | Spezifische Städte/Länder werden gefunden |
| Kein Key nötig | Anonymous Access funktioniert |
| Kein Code | Lab-Prinzip — MD-first, kein Python nötig |

### Integration mit visa-check

Wenn `check_visa` einen Visum-Bedarf feststellt:
→ `language-course` schlägt automatisch Kurse im Heimatland vor (DE lernen VOR der Ausreise)
→ Ergebnis: `"[Kandidat] kann in [Heimatland] Deutsch B1 lernen vor dem Visumsantrag"`
