# Onboarding-Vorlage – Deutschland

> Geltungsbereich: Alle Standorte in Deutschland  
> Rechtsgrundlage: AGG, BDSG, ArbZG, BGB

---

## Vertragliche Dokumente

| Dokument | Beschreibung | Frist |
|---|---|---|
| Arbeitsvertrag | Individueller Vertrag nach § 611 BGB | Vor Eintritt |
| Stellenbeschreibung | Detaillierte Aufgabenbeschreibung | Vor Eintritt |
| Betriebsvereinbarung | Sozialregelungen (falls vorhanden) | Tag 1 |
| Datenschutzeinwilligung | Einwilligung nach BDSG §26 | Tag 1 |
| Arbeitszeitkonto | Erfassung der Arbeitszeiten | Tag 1 |
| Gehaltsabrechnung | Monatliche Abrechnung | Monatlich |

## IT-Ausstattung

| Element | Standard | Verantwortlich |
|---|---|---|
| Laptop | MacBook Pro 14" / Dell XPS 15 | IT-Abteilung |
| Monitor | 27" External | IT-Abteilung |
| E-Mail | name@firma.de | IT-Abteilung |
| VPN | WireGuard / OpenVPN | IT-Sicherheit |
| Chat | Slack / Teams | IT-Abteilung |
| Password-Manager | 1Password / Bitwarden | IT-Sicherheit |

## Einarbeitungsplan

### Woche 1
- [ ] Tag 1: Begrüßung, IT-Übergabe, Sicherheitsbelehrung
- [ ] Tag 2: Tool-Einführung, Team-Vorstellung
- [ ] Tag 3: Prozess-Überblick, erste kleine Aufgabe
- [ ] Tag 4: Codebase/Prozess-Vertiefung
- [ ] Tag 5: Rückfragen, erstes Feedback

### Woche 2–4
- [ ] Eigenständige Aufgaben
- [ ] 1:1s mit Teamleitung (wöchentlich)
- [ ] Sprint-Teilnahme
- [ ] Zielvereinbarung (3 Monate)

## Checkliste HR

- [ ] Vertrag registriert
- [ ] Steuer-ID angefordert
- [ ] Sozialversicherungsmeldung
- [ ] GEZ-Meldung
- [ ] Betriebsrat informiert (falls vorhanden)
- [ ] Telefon/E-Mail auf Listen verteilt
- [ ] Wohnungssuche: Zielstadt + Einzugstermin, Bewerbungsmappe (Selbstauskunft, SCHUFA, Einkommensnachweise), Mietpreis-Range prüfen
