# Mehrsprachigkeit (i18n) — DE / EN / FR / AR

> **Stand:** 03.10.2026 · **Status:** Phasen 1–6 (inkl. 6b) umgesetzt
> **Ziel:** Sprachumschalter DE/EN/FR/AR auf Landingpage + Login + Kandidaten- + Arbeitgeber-Portal.
> **Lab-Prinzip:** Methode + Tools sind belegt (siehe Quellen); alle Werte = Design-Entscheidung.

## Quelle / Belege (Abruf 02.10.2026)
- **NiceGUI-Discussion #5840** (i18n): gettext + `_()` + `app.storage.user` + Reload ist der
  Community-/Maintainer-Konsens; keine offizielle i18n-API.
- **NiceGUI-Discussion #5045** + **PR #5058** (→ 3.0): RTL (Quasar) — `dir` wird zur Laufzeit gesetzt,
  RTL-CSS ausgeliefert.
- **Babel 2.11+**: extrahiert statische f-Strings (`babel.pocoo.org/en/latest/changelog.html`).
- **Ruff INT001** (`f-string-in-get-text-func-call`): Guard gegen f-Strings in `_()`.

## Architektur
- **gettext** (stdlib) + **Babel** (Extraktion/Kompilierung).
- `webui/i18n.py`: `get_language()` / `set_language()` / `_()` / `is_rtl()` / `apply_direction()`.
- Übersetzungen: `webui/locales/<lang>/LC_MESSAGES/messages.po` (+ `.mo`), Sprachen `de, en, fr, ar`.
- **Sprache je Session:** `app.storage.user["language"]` (Default `de`).
- **Umschalter** im Header → `set_language()` → `ui.navigate.reload()`.
- **RTL:** bei `ar` → `document.documentElement.dir = "rtl"` **und** Quasars RTL-Modus
  (`Quasar.lang.set({…rtl:true})`, Fix 03.10.2026). **Wichtig:** Quasar leitet sein RTL
  **nicht** aus `document.dir` ab — ohne das Flag reserviert `q-page-container` das
  Drawer-Padding auf der logischen statt physischen Seite (in RTL: Content unter der
  Nav-Sidebar). Nachweis: `ergebnisse/entscheidungen.md` (RTL-Bugfix) + `tests/e2e_rtl_drawer.py`.

## Konventionen (verbindlich)
- **Kein f-String in `_()`** → `_("{x} Bewerbungen").format(x=n)`; Guard: **Ruff INT001**.
- **Modul-Konstanten mit UI-Strings** (`_TAB_MAP`, `_MENU_ITEMS`, `PAGE_TITLES`, `_FAQ`, `_VORTEILE`,
  `STATUS_LABELS`) dürfen **nicht** import-zeit übersetzt werden → Labels erst in der
  **Renderfunktion** auflösen (sonst falsche Sprache nach dem Umschalten).
- **Rechtstexte** (Impressum/Datenschutz/AGB/Kontakt) laufen **nicht** über gettext, sondern über
  MD-Varianten `knowledge/legal/<name>.<lang>.md` (DE bleibt rechtsverbindlich).
- **E-Mails/Notifications** (agent-runner) brauchen die Sprache im **Task-Payload** (keine Session).

### Phase 5 — Candidate-Portal (03.10.2026)
- `webui/pages/candidate.py`: **180 msgids** in `_()` gewickelt (f-Strings → `.format()`,
  Ruff-INT001-konform); Kataloge `webui/locales/*/messages.{po,mo}` von **117 → 293** Keys.
- **Phase 5b (Nachzügler):** `section_header(title=/subtitle=)`, `empty_state(title=/description=/
  action_label=)`, `ui.number(label=)` und bedingte Button-Texte (`"A" if x else "B"` →
  `_("A") if x else _("B")`) waren im ersten Durchlauf **übersehen** worden (+27 Keys).
  **Nicht** übersetzt bleiben: Icon-Namen, `size=`-Werte, MIME-Typen, Routen-Pfade/-Keys, JS-Snippets.
- Sidebar-Labels: `_MENU_ITEMS` (Importzeit) ersetzt durch **`_menu_items()`**, Auflösung bei Renderzeit.
- **Nicht übersetzt (Design-Entscheidung):**
  - `PROFIL_*_OPTIONEN` (`ui.select`-**Werte**, landen in der DB) + `_PROFIL_SPALTEN` (Spaltennamen).
  - `VIDEO_HEADING = "## Video-Vorstellung"` und die MD-erzeugenden Helfer
    (`video_section_md`, `write_prescreen_md`, `persist_video_link`) — Speicher-Marker in `ergebnisse/`.
  - SQL, Dateipfade, `print`-Logs, DB-Notification-Text, Status-Rohwerte (→ Phase 8).
- Test: `tests/test_i18n.py` (4 neue Phase-5-Tests, gesamt **12**).
- Übersetzungen EN/FR/AR = eigene/maschinelle Erstfassung → Native-Review offen (s. u.).

## Offene Entscheidungen (Design-Entscheidung)
- Übersetzungsdienst: DeepL Free (500k Z./Monat) **oder** LibreTranslate/Argos (offline).
- AR-Fachreview vor Freischaltung (maschinelle Übersetzung).
- Landingpage-SEO: client-side Sprache → `?lang=`/Subpfad als spätere Option.
